# TGC CRYPTO

Digital Asset Market Platform powered by TGC GROUP.

## Files
- `index.html` — website structure
- `style.css` — dark responsive interface
- `app.js` — market data and interactive features

## Run locally
Open `index.html` in a modern browser with an internet connection.

## Deploy to GitHub Pages
Upload all three files to the root of a GitHub repository. In Settings → Pages,
select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.

Market data is requested from CoinGecko's public API. Availability and rate limits
are controlled by the API provider. Watchlist and portfolio data are stored locally
in the visitor's browser; this is not a real wallet or trading service.
